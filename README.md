# ワンタップデイト（One-Tap Date）

モニター版（試作品）

ワンタップデイト（One-Tap Date）の配布用ページです。
画面に浮かぶボタンを 1 回押すだけで、今日の日付を入力できる Android アプリです。
最新の APK は、右側の「Releases」からダウンロードできます。
